### **Things you may want to know:**
- As this is a python script, you would need to run `pip install -r requirements.txt`
- 'start.bat' will give you an option to run either of the scripts... 'yt2mp3.py' or 'convert.py'
- Other necessary details would be self-explanatory when you run 'start.bat'
- Keeping `yt-dlp` up to date will prevent common errors while executing the script
